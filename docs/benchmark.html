Methodology

  • Isolation - every measurement runs in a fresh Node subprocess. No JIT state carries between tests.
  • Warm-up - 500 ms minimum, with adaptive chunk sizing, stopping when drift over the last 8 chunks is <1.5 %.
  • Sampling - 12 × 500 ms windows per process; median used as the trial result.
  • Rotation - trial t starts at position t in the test list. Over 7 trials, every test appears at every position once. Thermal events that strike a position are shared evenly.
  • Aggregation - trial 1 is dropped (cold-machine noise), then median-of-medians with MAD and bootstrap 95 % CI from 2000 resamples.
  • CPU pinning - each subprocess is bound to one physical core at High priority; overall CPU is capped at 70 % to prevent thermal throttling.
  • Input - random coordinates from a 64 K-entry ring buffer, generated by xorshift32 (deterministic, no `Math.random`). This is what distinguishes this benchmark from the previous one, which fed identical inputs to every call and inflated all numbers by ~3×.
