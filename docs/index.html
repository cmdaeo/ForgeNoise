ForgeNoise

Procedural noise, but...
fast.

Perlin, Simplex, OpenSimplex2, Worley, Voronoi, fractals, tiling, and domain warping - one dependency-free library, in plain JavaScript.

Play games Try in browser View API See benchmarks

Install

From a CDN:

<script src="https://cdn.jsdelivr.net/gh/cmdaeo/ForgeNoise@main/dist/ForgeNoise.min.js"></script>

Quick start:

const noise = new ForgeNoise(1337);
const v = noise.generateSimplex2D(x, y);            // [-1, 1]
const f = noise.generateFractal2D(x, y, { octaves: 6 });

Algorithms

  • Perlin 1D / 2D / 3D / 4D
  • Simplex 1D / 2D / 3D / 4D
  • OpenSimplex2 F & S - 2D / 3D / 4D
  • Value 1D / 2D / 3D
  • Worley 2D / 3D
  • Voronoi 2D
  • Cellular (configurable metric, F1/F2/F2-F1/cellValue, jitter)
  • Fractals: fBm, ridged, turbulence, ping-pong, hybrid
  • Tiling 2D / 3D
  • Domain warp 2D / 3D
  • Analytic derivatives - Simplex 2D/3D, fBm 2D
  • [0, 1] range variants for every kernel

Benchmark snapshot

Against simplex-noise, open-simplex-noise, fastnoise-lite, and noisejs:

  • Simplex 2D - 2.03× faster than simplex-noise
  • Simplex 3D - 1.16× faster (borderline - confidence intervals barely touch)
  • Simplex 4D - tied at 0.98× (±2 %, within noise)
  • Value 2D / 3D - 6× faster than fastnoise-lite
  • Worley 2D - 1.98× faster than fastnoise-lite
